# Swiggy Landing Page 🍔

A Swiggy-inspired landing page built as a frontend practice project.

### 🛠️ Technologies

* HTML5
* Tailwind CSS v4
* Remix Icons

### ✨ Features

* Added custom hover effects and transitions to buttons, enhancing the original Swiggy design for practice.
* Search and delivery location inputs
* Food, grocery, and dining sections
* Responsive layout practice

### 👨‍💻 Author

Designed and coded by me from scratch for frontend practice, using the original website as a visual reference and adding custom hover effects.

### 📚 Purpose

Built to practise HTML, Tailwind CSS, Flexbox, and responsive design.

**Note:** This is a practice project and is not affiliated with Swiggy.
